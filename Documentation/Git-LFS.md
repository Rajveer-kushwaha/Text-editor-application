# Git Large File Storage (Git LFS)

## Purpose
Git LFS is used to manage large binary files that are difficult to store efficiently in normal Git history.

## Assets Suitable for Git LFS
- Large images and textures
- 3D models
- Audio and video files
- Large design files

## Benefits
- Keeps the normal Git repository lighter.
- Helps manage large assets.
- Supports version tracking for supported files.

## Usage Plan
Git LFS can be configured to track selected large files, such as .psd, .fbx, and .wav files, when required.

## Important
This document describes the planned use of Git LFS. Git LFS has not yet been configured in this repository.
