# Version Control and Rollback

## Purpose
Git tracks changes made to project files over time.

## Version Control Strategy
- main: Stores the stable project version.
- development: Used for ongoing development and testing.
- feature: Used to develop new features separately.

## Commit History
Meaningful commit messages help identify what changed and why.

## Rollback Plan
If a change causes a problem:
1. Review the Git commit history.
2. Identify the last working version.
3. Restore the required files or revert the problematic commit.
4. Test the project after recovery.

## Benefits
- Tracks project changes.
- Helps recover from mistakes.
- Supports safer development.
